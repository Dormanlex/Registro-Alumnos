# Registro-Alumnos
Un sistema para registrar alumnos, gestionar sus notas de ambos semestres y materias correspondientes, y calcular automáticamente sus promedios.

Tecnologías utilizadas
* Python 3.11.0
* Base de datos: SQLite3

Características
* Menú interactivo en consola.
* Registro, consulta y actualización de calificaciones.
* Persistencia de datos mediante SQLite.
* Limpieza de pantalla y flujo dinámico para el usuario.
